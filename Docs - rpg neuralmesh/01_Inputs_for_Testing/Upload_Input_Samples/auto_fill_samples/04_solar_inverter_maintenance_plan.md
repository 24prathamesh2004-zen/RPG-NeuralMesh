# Solar inverter maintenance plan, rooftop sites

Synthetic test file for NeuralMesh. Asvata facilities team, 2026.

Each rooftop inverter is cleaned every quarter and its cooling fan checked every month. Any work on the roof needs a valid work permit and two people on site. Inverter faults are logged with the site, the fault code and the hours since the last cleaning.

The plan covers twelve sites and is reviewed every year in March.
