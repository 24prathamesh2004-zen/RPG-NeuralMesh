# Why stored bales go stale

Synthetic test file for NeuralMesh. CEAT raw material team.

Bales kept too long in a damp store harden at the surface and lose plasticity. The oldest lots were found at the back of the bay, behind newer deliveries. From November the store issues the oldest bales first and marks each bale with its arrival week. Bales older than ten weeks go to the lab before mixing.
