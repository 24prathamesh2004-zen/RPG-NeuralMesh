RPG NeuralMesh Context Graph API

The APIs behind the three tabs of the Context graph page (Uploaded inputs, Upload input and Ingest data) and the query of a graph by its id. Each comes with what to send and what comes back. The examples were sent on 11 November 2026 to the running development API, on invented data.

How to call the context graph APIs

In short

  • 18 APIs: Sign in 1, Uploaded inputs 10, Upload input 3, Ingest data 3, Queries by graph id 1. Graph APIs lists what to send and what comes back for each.
  • Every call goes to the NeuralMesh API, http://127.0.0.1:8000 on the development stack, with the token in the header Authorization: Bearer. Only the sign-in needs no token.
  • A person signs in with email and password and gets a token valid for 12 hours. An application uses its service token, which sees only the graphs shared with the group and cannot ingest.
  • An uploaded graph is made from files on Upload input, and its id starts with g-. An ingested graph is written as JSON on Ingest data, and its id starts with cg-. The seven queries by graph id ask an ingested graph.
  • 14 of the 18 APIs were sent for the examples. The other 4 change data, an upload and three drops, so they show their request only.

Sign in

The answer holds access_token. Write it into TOKEN, and every curl command on this page sends it.

curl -s -X POST 'http://127.0.0.1:8000/api/v1/auth/signin' \
  -H 'Content-Type: application/json' \
  -d '{"email": "presenter@neuralmesh.local", "password": "<password>"}'

When something is wrong

HTTP codeMeaning
200The call worked. A check with check=true answers 200 and keeps nothing.
201The call made something new: an uploaded document or an ingested graph.
401The token is missing, invalid or expired. Sign in again.
403The token is fine, but the route needs a role the person does not have, for example an upload by someone who is not a mesh admin.
404The id is not there, or it is not shown to the caller. The two read the same, so a hidden graph is never revealed. A node name that is not in the graph gives 404 with the closest names.
409A name fits several nodes of a graph. The answer lists the candidates, so the caller can send the id of one.
413The JSON sent to ingest or query is larger than 8,000,000 bytes.
422A field needs a change. The answer says which field and what is wrong, and nothing is kept.

Queries by graph id

Every query is POST /api/v1/context-graphs/{graph_id}/query with one of the seven bodies below. The answer starts with graph and kind. The examples ask the ingested graph cg-1cc11e1e, invented data. A node is named by its id, its name or another name, in any case.

What is askedBodyWhat comes backRules
What does the graph hold{"overview": true}The number of nodes and edges, the node types with their counts, the edge types with their counts and the node types each one joins, and the number of nodes without edges.Nothing else is needed.
Find things by type, name or property{"nodes": {"type": "Supplier", "name": "part of a name", "properties": {"material": "FKM"}}}nodes (up to 200) and total.Give one or more of type, name and properties. type and properties must be equal (in any case), name may be a part of the name or of another name.
One thing and what is around it{"node": "Mixer 1", "hops": 1}node, its neighbours and the edges walked to reach them, with totals.The node is named by its id, its name or another name, in any case. hops is 1 or 2, 1 when missing.
Relationships{"edges": {"type": "SUPPLIES", "source": "Supplier X", "target": "Rotor seal RS-200"}}edges (up to 500), each with its type, its source and target nodes and a line of text, and total.Give one or more of type, source and target. relationships is read as another name for edges.
How two things are connected{"path": {"from": "Supplier X", "to": "Plant A", "max_hops": 4}}hops and paths: up to 3 shortest ways, each a list of edges and a line of text.An edge is walked in either direction and given back as it is stored. max_hops is 1 to 6, 4 when missing. When no way is short enough, paths is empty with a note.
What is similar to one thing{"similar": {"node": "Supplier X", "top": 5}}similar: nodes of the same type, each with a score, the shared neighbours and the reason, and total.The score is the shared neighbours divided by all the neighbours of the two (the Jaccard index), from 0 to 1. top is 1 to 20, 5 when missing.
A question in plain words{"question": "Which suppliers supply the rotor seal?"}matched nodes, numbered nodes (N1 onwards) and edges (E1 onwards), and an answer that cites them, or answer_note saying why there is no written answer.Code finds the nodes the question names and the edges around them. The answer model writes only when the model rules allow it for the graph, and a sentence that cites no given node or edge is left out. A graph with synthetic false never reaches a cloud model.
