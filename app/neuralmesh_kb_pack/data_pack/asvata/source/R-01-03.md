Count the rows and compare with the count the client stated. Remove exact duplicates and log how many were removed. Mark missing values and do not fill them silently. Check each column against its expected range, for example a month number between 1 and 12. The raw file stays untouched and all changes are made on a copy. If more than 5 percent of a key column is missing, the file goes back to the client.
