Before energising, insulation resistance is measured between each core and earth. A high voltage withstand test is applied for the agreed time and the leakage current is watched. For cables above medium voltage, a partial discharge test is run and the level is compared with the site limit. A reading below the insulation limit or above the discharge limit stops energising. Each result is written in the test report.
